# 🗺️ Roadmap du Projet

## Objectif

Ce document présente l'état d'avancement du projet **Tout y est**.

Il permet de connaître :

- les fonctionnalités terminées ;
- les fonctionnalités en cours ;
- les prochaines étapes ;
- les évolutions prévues.

La roadmap sert de référence pour planifier les développements futurs.

Le projet est organisé en plusieurs grandes phases :
